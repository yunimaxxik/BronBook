# BronBook — Сайт-агрегатор поиска и бронирования книг в библиотеках

Дипломный проект курса «Fullstack-разработчик на JavaScript» (Нетология).

## Описание проекта

BronBook — это веб-приложение для поиска и бронирования книг в различных
библиотеках. Проект реализует полный цикл работы с книгами: от каталога и
фильтрации до бронирования на выбранную дату и общения с техподдержкой в
реальном времени.

### Основные возможности:

- Аутентификация и авторизация (клиент, менеджер, администратор)
- Каталог книг с фильтрацией по названию, автору, библиотеке и доступности
- Детальные страницы книг с возможностью бронирования
- Система аренды книг с управлением статусами
- Чат техподдержки с WebSocket для мгновенной доставки сообщений
- Админ-панель для управления библиотеками и книгами
- Панель менеджера для обработки обращений в поддержку

## Технологии

### Backend:

- **Node.js** + **NestJS** — фреймворк для серверной части
- **TypeScript** — типизация
- **PostgreSQL** — база данных
- **TypeORM** — ORM для работы с БД
- **Passport.js** + **express-session** — аутентификация через сессии
- **Socket.io** — WebSocket для чата
- **EventEmitter** — система событий для оповещений
- **Multer** — загрузка файлов (обложки книг)
- **class-validator** + **class-transformer** — валидация DTO

### Frontend:

- **React 18** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Redux Toolkit** — управление состоянием
- **React Router** — маршрутизация
- **Axios** — HTTP-клиент
- **Socket.io-client** — WebSocket клиент
